# Radioactive Decay Representation with Python

An early Python simulation that models radioactive decay with repeated random trials and visualizes the result.

## What it uses

- Python
- Tkinter
- pandas
- matplotlib

The program provides a small desktop interface for configuring the simulation, writes generated data to CSV, and plots the remaining undecayed population over time.

## Run

Install the dependencies:

```bash
pip install pandas matplotlib
```

Then run:

```bash
python proyecto.py
```
